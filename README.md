# Sally Face PSVita Port

**YOU NEED TO BUY THE GAME ON STEAM TO MAKE IT WORK!**

## How to apply the patch

- Download the Sally Face vpk and install it.
- Go to the Release page and download ``SallyFaceVitaSTEAM.zip``.
- Extract it.
- Put the game's folder (```..\steamapps\common\Sally Face```) inside the extracted folder.
- Run ``ApplyPatch.bat`` and wait.
- Let it finish and there should be a .ZIP file named ``SallyFaceVITA_FILES.zip``.
- Open VitaShell, connect your PS Vita to your PC and copy the ``Media`` folder from inside the .ZIP over to ``ux0:app/SAFA01000/``.

Any bugs report in Issues!
